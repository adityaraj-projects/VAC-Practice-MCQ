--- PAGE 4 ---
Frontend vs Backend
Frontend (Client -Side)
The visual interface user interacts with. Built using HTML, CSS, JavaScript, React, Angular.
Backend (Server -Side)
The hidden engine executing business logic, security, and database queries. Powered by 
Python & Flask.
--- PAGE 5 ---
Client -Server Architecture
1. Client (Browser)
Captures user action, formats HTTP Request, and 
renders received HTML payload.
2. Server (Flask)
Processes incoming route requests, executes 
Python code logic, builds response.
3. Data Layer
Stores permanent records (SQLite, MySQL) 
queried dynamically by the server.

HTTP Method Core Action Real -World Example Context

Introduction to Web Frameworks
Building Without a Framework
Developers must manually write raw socket handling, HTTP message parsing, 
manual URL matching, and header management from scratch.Building With Flask Framework
Framework provides pre -built routing, session handling, templating, and 
request processing out -of-the-box so you focus purely on app logic.
--- PAGE 11 ---
Flask Features & Background
Micro Framework
Lightweight core created by Armin Ronacher in 
2010. Simple, flexible, unopinionated.
Built on Werkzeug & Jinja2
Uses Werkzeug for WSGI routing/HTTP handling 
& Jinja2 for dynamic HTML templating.
Built -in Server & Debugger
Includes development web server and interactive 
debugger for rapid local testing.

--- PAGE 12 ---
Flask vs Django Overview
Comparison Feature Flask (Micro Framework) Django (Full -Stack Framework)
Philosophy Minimalist & Unopinionated "Batteries Included" (Monolithic)
Setup Complexity 1 File (`app.py`), 5 lines code Multiple pre -generated config files
Database Layer Pluggable (SQLAlchemy, Mongo) Built -in Django ORM
Best Suited For APIs, ML Deployment, Microservices Large Enterprise monoliths
--- PAGE 13 ---
When to Choose Flask or Django
Choose Flask When: Choose Django When:
Learning backend concepts without unnecessary complexity
Building lightweight REST APIs & Microservices
Deploying Machine Learning models (AI)
Creating student projects and prototypes
Building large E -Commerce / ERP systems
Built -in admin panel and user auth are required
Working with large teams following rigid structure
Enterprise applications with built -in ORM
